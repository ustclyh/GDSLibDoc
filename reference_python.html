Bases: object

Paths 类

该类用于构建由多边形定义的路径。其方法分为两大类：路径初始化和结束；路径的绘制。

基本使用逻辑为：使用 new_path 方法初始化一条路径，随后通过若干 add_* 格式的方法，加入 直线，弯曲以及spline 等路径。当一条路径绘制完成后，调用 end_current_path 方法，将此路径添加入 path_list 。 重复以上过程，将若干路径加入 path_list ，当完成全部路径定义后，调用 generate_pcell 方法， 从当前 path_list 生成Pcell。

当连续调用 add_* 格式的方法时，该类会自动记录路径末端的坐标、斜率以及曲率，用于所添加路径的自动平滑拼接。

end_current_path(start=None, width=None, layers=1, max_evals=50000, add_copy=False, auto_new=False)

将当前路径添加入path_list, 并结束当前路径, 并根据情况开始一段新路径.

当start参数非空时, 会开始一段新路径. 当参数 start 为空, 且 auto_new 为假时, 此方法仅将当前路径对象加入 self.path_list, 但不会刷新 self.curPath. 此时用户可以调用 self.curPath 的方法进行镜像等操作.

但需注意, 若此前该路径已经加入 self.path_list, 但参数 add_copy 为假, 对 self.curPath 的变换将影响此前已加入 self.path_list 的对象. 为避免这一情形发生, 请将参数 add_copy 设置为真, 此时方法将生成 self.curPath 的拷贝将此加入 self.path_list.

Parameters

  • start (array[1][2]) – 新路径起始坐标

  • width (array) – 路径宽度

  • layers (array) – 放置路径的layer

  • max_evals (int) – 生成多边形时，计算的点数. 当需求的多边形顶点超过此数后，路径将生成不全.

  • add_copy (boolean) – 如果为真，加入path_list的是当前路径的一个拷贝，接下来如果进一步对此路径进行镜像等操作，将不会影响已经添加路径的结果.

  • auto_new (boolean) – 当start为空时，若auto_new为真，将自动在原地，以原先宽度初始化一段新路径

Device

class Devices.Device(name='Device')

Bases: Paths, Polygons, References

Device 类

该类应当是 Devices 中所有器件的父类， Device 提供了器件构建的通用方法。

在一次芯片构建过程中，在程序的第一部分，需初始化所需全部 Device （器件）。 当 Device 类中全部参数确定为所需后，调用 generate_cell 方法，程序会基于当前参数生成放置该期间的 Cell ， 并自动计算 md5 值用于器件命名。 所有所需器件，一旦调用 generate_cell 方法，便被加入静态字典 devList 中，键值为自动生成的器件名。 generate_cell 方法会返回自动生成的器件的 Cell，可通过 Cell.name 获取生成器件的名称，用于芯片构建过程中的进一步调用。 器件的端口信息，以字典的形式存储于静态属性 devDict 中。

此类继承了 Paths 和 Polygons，因此其中包含存储器件所包含路径以及多边形的列表。 此外，此类还添加了与端口相关的属性，用于系统级的芯片构建。

此类还与 heater 绘制相关，有两种策略： 一、请在器件定义（即自定义 Device 类的子类）时，添加 heater_box 属性，并以 [array([x1, y1]), array([x2, y2])] 的格式存入 box 的左下和右上坐标，HeaterGenerator 会基于此绘制 heater。 二、如已定义非标准 heater （比如环腔），请将 heater 的两个用于连接的 Pad 坐标以 [array([x1, y1]), array([x2, y2])] 格式 存入自行添加的属性 heaterPad。

该类还提供了静态方法，用于将由程序包 gdsfactory 生成的 Component 对象直接注册至器件的 PCell 列表， 用于此程序包与基于 gdsfactory 所定义器件库的兼容性匹配。

add_reference(obj: str, id: Optional[str] = None, trans=None, rotation=0, x_reflection=False, heater=False)

直接添加 PCell 的引用。 参数 obj 为特定器件的注册名称（默认在 generate_cell 时自动根据类的 md5 值生成）， 参数 id 为引用对象的 id，用于区分对于同一器件的不同引用。器件名称与 id 共同构成引用的名称。 引用名称（即 id ）的唯一性非常重要，器件名称（即实例化器件时给定的名称）+ id共同构成于GDS版图显示的器件Label，并用作heater绘制的标识符。 引用可引入平移，旋转以及对称。

Parameters

  • id (str) – reference 的 id

  • trans – 位移

  • rotation (double) – 旋转角度（弧度制）, 默认为 0

  • x_reflection (bool) – 是否对于 x 轴对称, 默认为否

  • heater (bool) – 是否需要heater
