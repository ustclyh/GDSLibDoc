添加 Heater

程序包还提供了 heater 的相关绘制功能. 在调用相关方法之前, 我们需要在绘制芯片时加入相关代码, 生成与heater放置相关的配置文件. 以芯片构建的例子说明, 在 MZI22 器件的定义时, 我们需给定类的属性 heater_box, 存放绘制heater的盒子坐标.

self.heater_box = np.array(delay_short.cell.bounding_box())

在构建芯片, 初始化基本器件后, 用器件对象生成 HeaterBox 对象, 并注册, 代码如下

MZI_22 = MZI22("MZI")
mzi_n = MZI_22.generate_cell().name
HeaterBox(MZI_22)

并在程序结束加入如下代码

dict_heat_xy = chip.heater_list
dict_obj = HeaterBox.heater_dict
np.savez("heater_info.npz", heat_xy=dict_heat_xy, obj_info=dict_obj)

放置 Heater

以下代码便完成了放置 heater

from ChipConstructors import HeaterGenerator
infofile = "heater_info.npz"
heater = HeaterGenerator(infofile)
# heater.add_heater_box()
for i in range(1, 9):
    heater.draw_heater("MZI" + "_" + str(i))

其中给入方法 draw_heater 的参数即通过chip构建方法, 在gds文件中所显示的label. 我们接下来希望能够将heater引线至芯片边缘. 因此, 需要在芯片边缘放置用于外部引线的pad, 以及将heater连接至pad上.

绘制 pad 的代码非常简单, .. code-block:: python

heater.add_edge_pad(list(range(-2350, 2350, 150)), [2300, -2300])

仅需给定 x 和 y 坐标的list即可, 程序会自动mesh得到pad阵列. 接下来的引线也较为简单, 代码如下 .. code-block:: python

heater.add_wire(“MZI_4”, 1, [[-10, 0], [0, 1800], [0, 300]], 10)

其中, 第一个参数为显示于 GDS 版图中的器件label, 第二个参数为heater的Pad编号, 第三个参数为路径参数. 路径参数是 [dx, dy] 构成的列表. 最后一个参数是 add_edge_pad 方法生成Pad的编号, 程序会自动从指定路径末端连接至该Pad.
